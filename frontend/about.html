About Deep-Fake Guard

Deep-Fake Guard is designed as an enterprise-grade forensic tool and academic project demonstration to counter synthetic media manipulation.

Core Technologies Used

  • Frontend: HTML5, Responsive CSS3, JavaScript (Fetch API)
  • Backend REST API: Python, Flask, Flask-CORS
  • Machine Learning: TensorFlow/Keras, MobileNetV2 Transfer Learning
  • Image & Video Processing: OpenCV and Pillow
  • Data Integrity: SHA-256 Cryptographic Hashing
  • Database Storage: SQLite lightweight relational engine

How Integrity Verification Works

The SHA-256 hash calculator generates a 64-character cryptographic checksum unique to the uploaded file. Even a single-pixel modification changes the resulting hash entirely. Comparing this hash to an original verified source code or ledger ensures the file has not been altered maliciously in transit.
